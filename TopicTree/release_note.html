    This topic explains how to use bar charts in Lyric Studio, including when to use them, how to add and configure them, and how to customize their appearance. It also includes release notes that communicate the value of the new bar chart feature.

    • How to add bar chart

      A bar chart shows values for different categories as rectangular bars. It helps you compare values across groups and quickly see differences in size. In Apps Studio, you can add a bar chart to an interface page and configure it by selecting fields for the X-axis and Y-axis. You can also adjust the chart title and style settings.

      • New chart type: Bar Chart

        Apps Studio now supports Bar charts, giving users a simple way to compare values across categories. Whether you are reviewing regional performance or comparing key measures side by side, bar charts make data easier to review visually.

      • Introduction to Bar Chart

        As part of this release, a Bar chart has been added to the list of available chart types in Apps Studio. This feature gives users a visual way to compare values across categories and review multiple measures side by side within an interface page.Users can add a Bar chart, select fields for the X-axis and Y-axis, and apply basic style changes such as chart title, series colors, and labels. This addition helps make category-based data easier to review and interpret.
